# Pack: .NET + Angular

Example stack pack, layered on [`neutral`](../neutral/). Use it with a .NET back end (ASP.NET Core or Azure Functions isolated worker) and an Angular front end. Pin the versions in your project; these rules follow the current upstream guidance for recent major versions.

- [backend.md](backend.md): C# and .NET conventions
- [frontend.md](frontend.md): Angular conventions
- [gates.md](gates.md): suggested pre-commit gates for `team.config.yaml`

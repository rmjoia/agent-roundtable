# Changelog

All notable changes to this template. Adopters see the entries newer than their version when they run `/sync-team`. Format: [Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions follow [SemVer](https://semver.org/): a role or template change that changes generated output is at least MINOR; a config-schema change that needs new answers is MAJOR.

## [Unreleased]

### Added
- `prompts/bootstrap.md`: a prompt for setting up the team with any AI assistant (GitHub Copilot, ChatGPT, Cursor, Gemini …), which drafts an adapter at the end.
- `adapters/`: the adapter contract and template, the Claude Code reference adapter and a generic `AGENTS.md` fallback.
- `scripts/install.sh` also copies `adapters/` and `prompts/`.

### Changed
- Personas gain an optional *Your personality* section: a theme's `personality` per role (a working trait and an off-duty love), rendered by `{{personality}}` and dropped when a theme has none. `arthurian` carries all 13; other themes are unchanged. A shared rule (and a roster line) say personality colours the voice, never the work: it never overrides the charter, the lane, the honesty pact or the report limits. Role versions bumped.
- Personas name the craft they stand on: Robert C. Martin, Kent Beck, Michael Feathers, Mark Seemann, Martin Fowler, Freeman and Pryce, Farley and Humble, where each fits (architect, front end, both back ends, QA, DevOps; role versions bumped).
- `neutral` pack: an *Influences* section, and *Working with existing code* (characterisation tests, seams, small behaviour-preserving refactors, sprout and wrap).

## [0.1.0] - 2026-10-28

### Added
- 13 canonical role templates (`roles/`); only the architect is required.
- Themes: `neutral`, `arthurian`, `greek`, `roman`, `norse`, `egyptian`, `astronomy`; `themes/local/` for your own.
- `team.config.yaml` schema and an annotated example.
- `scripts/render.py`: a deterministic renderer (Python 3 + PyYAML) used by `/init-team` and `/sync-team`.
- `/init-team`: a one-question-at-a-time interview that renders the team into a staging folder, shows the diff, and writes on approval; idempotent.
- `/sync-team`: pulls template updates and re-renders, keeping names, lanes and local persona blocks.
- `/self-review`: a read-only review of any diff against the self-review lens.
- Templates: roster, CLAUDE.md team section, PR template, story/task/bug/retro issue templates, task/review/decision briefs, Definition of Done, pre-commit and commit-msg hooks.
- Packs: `neutral` (Definition of good code, contracts, RFC 9457 API errors, testing, OWASP security, accessibility) and a `.NET + Angular` example.
- Docs: roles, lanes, review gates, task briefs, retro loop, sync (down and up), requirements and cost.
- Examples generated by `/init-team` for two fictional projects.
- Inert workflow templates for downstream sync and the upstream contribution design.
